# User documentation

Assembly BASIC assumes familiarity with Commodore 64 BASIC V2. Start with the [README's differences and quick example](../README.md#use), then use these references:

- [Language reference](LANGUAGE_REFERENCE.md): syntax, numeric types, all supported statements/functions, extensions and limits.
- [Source editor](SCREEN_EDITOR.md): keyboard controls and editing programs.
- [Binary and sprite editor](BINARY_EDITOR.md): reserved memory, blobs, hex editing, sprite painting and binary files.
- [Stock BASIC PRG import](PRG_IMPORT.md): conversion rules and compatibility limits.
- [Host source tools](HOST_TOOLS.md): text/container conversion and the instruction-level console.
- [Examples](../examples): programs to enter or encode; matching native files are in [dist/examples](../dist/examples).

Build instructions, test coverage, known implementation gaps and debugging records are in [implementation](implementation/README.md). Architecture and format specifications are in [design](design/README.md).
